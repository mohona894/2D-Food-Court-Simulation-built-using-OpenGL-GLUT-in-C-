# 2D-Food-Court-Simulation-built-using-OpenGL-GLUT-in-C-

This project is a **2D animated Food Court Simulation** developed using **C++ and OpenGL (GLUT)**. The scene represents a modern university food court environment with different campus buildings, food stalls, roads, vehicles, pedestrians, trees, and moving clouds. Various animations make the environment look more realistic and interactive.

## Features

* University campus with DIU, CSE and EEE buildings
* Four food stalls: Pizza, Burger, Noodles and Drinks
* Animated moving cars on the road
* Animated pedestrians walking on the roadside path
* Smooth moving clouds
* Trees, greenery, and roadside decorations
* Tables, chairs, and people sitting in the food court
* Road with lane markings and walking pavement
* Colorful graphics created using OpenGL primitives
* Press **ESC** to exit the application

## Technologies Used

* C++
* OpenGL
* GLUT (OpenGL Utility Toolkit)
* Code::Blocks IDE

## Scene Overview

The project creates a lively university food court where:

* Cars continuously move in opposite directions.
* People walk along the roadside walkway.
* Clouds move slowly across the sky.
* Multiple buildings and food stalls create a campus atmosphere.

## How to Run

1. Install **Code::Blocks** with MinGW.
2. Configure **OpenGL** and **GLUT** libraries.
3. Open the project source file.
4. Build and run the program.

## Project Structure

* Drawing functions for buildings, trees, cars, people, tables, and food stalls
* Animation update function using `glutTimerFunc()`
* OpenGL rendering using basic geometric primitives
* Keyboard handling for exiting the program

## Learning Objectives

This project demonstrates:

* 2D graphics using OpenGL
* Object-based drawing with reusable functions
* Animation using timer callbacks
* Scene composition and coordinate system
* Basic computer graphics concepts
